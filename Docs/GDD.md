## 1. Концепт

### 1.1 Питч
**Scrapheart** — 2D top-down roguelike, где ты сплавляешь два оружия в одно в кузнице падшего кузнеца и спускаешься к его Сердцу, которое сплавляет всё живое в подземелье.

### 1.2 Фантазия игрока
«Я — герой с последнего тёплого дома на краю разлома. Я кидаю в наковальню две несовместимые вещи и получаю безумное оружие, которого не было ни у кого».

### 1.3 Опорные принципы (pillars) ◆
Фильтр для каждой новой фичи (правила C2, C11): если не усиливает ни один принцип — в backlog или вырезать.

| # | Принцип | Обещание игроку | Правило дизайна |
|---|---|---|---|
| 1 | **Сплав — сердце игры** | «Хочу проверить эту безумную пару» | Всё, что даёт оружие, должно кормить кузницу. Сплав необратим, результат удивляет, но читается. |
| 2 | **Честный быстрый бой** | «Я умер, но понимаю почему» | Телеграф раньше урона, нечестных атак нет (п.86), смерть → быстрый перезапуск. |
| 3 | **Лом и швы** | «Узнаю игру по одному кадру» | Всё сшито и склёпано: швы, заклёпки, ржавчина, угли, пульсирующее Сердце (п.143). Не похоже на Soul Knight. |
| 4 | **Тёплый дом** | «Даже неудачный забег что-то открыл» | Поместье открывает контент, а не продаёт силу. |

### 1.4 Отличие от конкурентов
Жанровые конвенции (top-down, комнаты с волнами, 2 слота, редкость, боссы) берём как есть — игрок их знает (C12). Уникальность:
- **сплав двух оружий** в физической кузнице (п.5–12, 104–108);
- **враги-химеры** — Сердце сплавляет и врагов (п.142);
- **визуал «лом и швы»** (п.143);
- хаб без прямых копий Soul Knight (п.144).

### 1.5 Платформа и рамки
PC (Steam), Windows (п.3). Unity 6, C# (п.66). Цена $5 / ~$3 регион (п.59). Без внутриигровых покупок, DLC — только скины.
Ввод в срезе: мышь + клавиатура (п.123). Геймпад, Steam Deck — 1.0 (п.60).

### 1.6 Тон и сюжет (кратко)
Тёплая тёмная сказка: мрачное подземелье + уютный дом, лёгкий юмор (п.45).
Франкен — гениальный кузнец, сшивший себя из лучших изделий ради бессмертия: рука-молот, клинки как рёбра, в груди светится Сердце-горнило, кожаный фартук (п.46, 119). Его Сердце растёт и затягивает людей и вещи сверху; поместье — последний тёплый дом на краю разлома; герои спускаются остановить его и спасти затянутых (п.116). **В срезе сюжета нет** (п.118).

## 2. Вертикальный срез (сдача: середина января 2027)

### 2.1 Что сдаём (п.64–66)
Игра + этот GDD + репозиторий + небольшая презентация.

### 2.2 Состав (п.65, 120–123)
| Область | В срезе |
|---|---|
| Герои | Рыцарь, Маг (Маг открывается за кристаллы) |
| Биом | Замок: 4 этажа + босс Голем из доспехов |
| Оружие | 12 + оружие босса «Кулак Голема» (§7.1) |
| Сплав | Полностью: кузница, доминанта, джекпот, перековка, дневник сплавов |
| Бой | Статусы огонь / лёд / шок / яд; 15 пассивок; проклятия + святилище |
| Враги | 9 видов + мини-босс Капитан стражи + 2–3 химеры (п.142) |
| Мир | Торговец, мини-босс, секретные стены (бомбы), комната-фонтан, клетка помощника, модификаторы комнат |
| Поместье | Главный зал + выбор героя + портал; тренировочный зал; кристаллы + открытие Мага; 1 питомец (⚠ см. §13, вопрос 2) |
| Пролог | 5 комнат обучения, без сюжета (п.140) |
| Техника | Языки RU / EN / PL. Без коопа, без сейва между этажами, без геймпада |

### 2.3 Порядок урезания (если к 5.01.2027 не успеваем) (п.124–125)
1. Проклятия/святилища + мини-босс.
2. Оружие 12 → 8, пассивки 15 → 8.
3. Остальное (статусы, модификаторы, питомец, польский, секретные стены, помощник) — только после вопроса владельцу.

**Нельзя резать:** сплав, бой, босс, оба героя, поместье-хаб, торговец.

### 2.4 Порядок производства ◆
1. **Серая коробка** (п.151): герой, 2 оружия, сплав, 1 враг, 1 комната с волнами — без арта, на целевой архитектуре.
2. Плейтест владельца → правки → цикл короткими поставками (B4).
3. Этаж: граф + чанки + сундуки + портал.
4. Все враги и оружие по данным; пассивки, статусы.
5. Босс, мини-босс, торговец, проклятия.
6. Поместье, пролог, локализация.
7. Арт по art bible поверх плейсхолдеров (D1, G8), звук, game feel.
8. Полировка, презентация.

### 2.5 Сценарий первого часа (C6) ◆
| Минута | Игрок | Чему научился / чего хочет |
|---|---|---|
| 0–5 | Пролог: 5 комнат | Ходьба, прицел, стрельба, смена оружия, dash, бой, первый сплав |
| 5–7 | Поместье | Выбор Рыцаря, видит Мага за кристаллы, портал |
| 7–20 | Этажи 1–2 Замка | Сундуки, первая кузница, первая пассивка 1 из 3, торговец |
| 20–35 | Этажи 3–4 | Элиты, химера, мини-босс (шанс), проклятие/святилище, сильный сплав |
| 35–45 | Голем | 3 фазы, награда: сильная пассивка, шанс «Кулака Голема», кристаллы |
| 45–60 | Смерть или победа → поместье | Экран итогов, кристаллы → открыть Мага, хочется попробовать новую пару в кузнице |

### 2.6 Цели трёх горизонтов (C5)
- **Сейчас:** пережить волну, выбрать оружие из сундука.
- **Этаж:** найти кузницу и собрать сплав, дойти до портала.
- **Долго:** победить Голема, накопить кристаллы на Мага, заполнить дневник сплавов.

## 3. Основной цикл (C3)

```
Поместье → портал → этаж: [комната → бой (двери заперты, 2–3 волны) → сундук → выбор]
        ↑                       ↓ кузница: 2 оружия → 1 гибрид
        |                       ↓ после этажа: пассивка 1 из 3
        |               4 этажа → босс → награда
        └── смерть/победа ← итоги, кристаллы
```

### 3.1 Забег (п.68–71, 75, 82)
- Полный забег 1.0 — 60+ минут; этаж ~3 мин, боссы дольше.
- Бой в комнате: вошёл → двери запираются → 2–3 волны → награда → двери открываются.
- Портал на следующий этаж — только после зачистки всех боевых комнат.
- Камера следует за игроком со сдвигом к прицелу.
- Смерть: экран итогов (этаж, убийства, время, билд, кристаллы).
- Воскрешение: редкая находка «Запасное сердце» (босс / торговец), срабатывает автоматически, не гарантировано (п.72).
- Сейв между этажами — 1.0 (п.69), в срезе нет.

### 3.2 Мини-карта (п.99)
Туман; видны соседние комнаты; иконки — когда заглянул. Телепорта нет.

## 4. Герои

### 4.1 Общие правила
- Числа крупные: HP героя 100+, урон врагов 10–30 (п.73).
- **HP** не регенерирует (п.76).
- **Броня** — щит-полоса, восстанавливается через 3 с без урона. Удар больше остатка брони ломает её, излишек в HP **не проходит**. Броня защищает и от яда/горения (п.131, старый GDD §08).
- **Мана** — тратится оружием (§5.3); навыки героев бесплатны.
- **Dash**: 1 заряд, кулдаун ~1 с, i-frames, у каждого героя свой вид (п.74). Пассивка может дать 2-й заряд.
- **Ульта**: кулдаун ~60 с (п.91).
- **Крит**: 5% базово, x2 (п.19, 109).
- Контакт с врагом наносит урон; долгих i-frames после попадания нет (старый GDD §08).

### 4.2 Герои среза (п.90, 109)
| | Рыцарь | Маг |
|---|---|---|
| HP / броня / мана | 120 / 60 / 150 | 80 / 30 / 250 |
| Старт | Вечный меч | Искровой посох |
| Dash | Щитовой рывок, толкает врагов | Короткое парение сквозь угрозу |
| Навык | Блок / контрудар | Цепная молния |
| Ульта | 10 с бастиона | Грозовая сфера |
| Открытие | Сразу | За кристаллы |

Цифры — для калибровки, финал в `Docs/COMBAT_BALANCE.md` после плейтестов (E7, E9).

### 4.3 Выбор героя (п.111)
Подошёл к герою в зале → E. Неоткрытые — силуэтами с ценой.

## 5. Оружие

### 5.1 Слоты и подбор (п.20, 106)
- 2 слота. При подборе третьего текущее падает на пол и лежит до конца этажа.
- Карточка при подходе (п.79): название, редкость, урон, мана, элемент, стрелки ↑↓ сравнения; у сплавов «родители: A + B».
- Рост оружия в забеге — только сменой и сплавом (п.16).

### 5.2 Редкость (п.78)
Обычное (белый) · редкое (синий) · эпическое (фиолетовый) · легендарное (золотой) · **«Франкен»** (оранжевый) — только сплавы. Идеальный сплав — переливающийся.

### 5.3 Ресурс (п.21)
- Стартовое и ближнее оружие без снаряда/волны — **0 маны**. Остальное тратит ману.
- **Перегрев** — отдельная механика части оружия (вместо маны).
- Мана восполняется сферами с врагов и зельями.

### 5.4 Урон и снаряды (п.18–19)
- Физический урон + элементы; у врагов слабости/резисты по биому.
- Моды снарядов: рикошет, пробитие, разрывные/делящиеся — свойства оружия или пассивок.
- Самонаводка — свойство конкретного оружия.

### 5.5 Прицел (п.110)
Мышь — точно по умолчанию; assist aim — опция доступности. Оружие вращается за прицелом на 360° (п.147).

## 6. Сплав (USP)

### 6.1 Кузница (п.11, 104–105)
- Появляется случайно на 30–50% этажей.
- Физически: две плиты на наковальне, подошёл → E → положил оружие из рук (можно принести с пола). Рычаг → ритуал → гибрид падает на пол. **Без меню.**
- Сплав бесплатный: цена — потеря двух оружий и риск доминанты.
- Стартовое оружие можно сплавить, оно исчезает (п.10).

### 6.2 Правила результата (п.5–8, 12)
- **Доминанта** — случайно при ковке: A / B / середина.
- **Наследование:** визуал — от оружия большей редкости; смешиваются все статы: урон, крит, эффект атаки, тип атаки, способности.
- **Превью нет.** Закинул → ритуал → гибрид.
- **Пересплава нет.** Гибрид — финальная форма.
- **Джекпот:** любая пара, шанс 2–3% — «идеальный сплав» (100% статов обоих).

### 6.3 Страховка (п.9)
- **Перековка** за золото, 1 раз на кузнице.
- **Дневник сплавов:** повторная пара показывает, что может выйти.

### 6.4 Подача (п.95, 108)
- Обычный сплав — ритуал 3–4 с: оружия взлетают → искры/молот → вспышка цвета редкости → гибрид падает с названием + реплика Франкена из темноты. Пропускаемо.
- Длинная катсцена с Франкеном — только: первый сплав в игре, джекпот, новая пара в дневнике. ⚠ В срезе Франкена нет (п.118) → в срезе только ритуал ◆.
- Вид гибрида: спрайт более редкого оружия + сменная деталь второго (дуло, клинок, кристалл) + цвет элемента + швы/заклёпки. Собирается **из слоёв**, без отрисовки каждой пары.

### 6.5 Пример
Обрез + Посох углей → «Огнедробь»: веер огненных дробин с горением; корпус обреза, огненный кристалл на стволе.

| Мимик | 90 | 20 | Притворяется сундуком (дышит). Дроп как с обычного врага | Удар по сундуку издалека |
| Гаргулья | 80 | 10 / 18 | Пока в комнате есть враги — неуязвимая статуя, плюётся камнями; после смерти последнего оживает, пикирует | Укрытия, добить в полёте |

**Телеграф** (п.86): красные зоны на полу для больших атак + замах 0.4–0.8 с + свечение оружия.

### 7.5 Химеры (п.142) ◆
Элитные враги = сплав двух базовых. В срезе 2–3. Правило-предложение (утвердить, §13 вопрос 3):
- HP = сумма HP родителей × 0.8; поведение основного родителя + одна способность второго;
- визуал: тело основного + деталь второго + швы/скобы Сердца (как гибрид оружия, из слоёв);
- кандидаты: **Скелет + Слизень** (мечник, при смерти делится на 2 скелета-слизня), **Крыса + Летучая мышь** (стая, прыгающая через укрытия), **Щитоносец + Гаргулья** (щит неуязвим, пока жива стая).

### 7.6 Мини-босс: Капитан стражи (п.31)
HP 400, урон 18–25. Скелет с алебардой: выпад по линии, круговой взмах, зовёт 2 мечников на 50% HP. Своя арена + сундук. Шансовая комната ~30% этажей.

### 7.7 Босс: Голем из доспехов (п.85, 88–89), HP 1500
- **Фаза 1 (100–66%)**: удар кулаком (круг на полу, замах 1.0 с, 30); ударная волна (кольцо, пройти dash-ем сквозь, 20); бросок 3 шлемов веером (15).
- **Фаза 2 (66–33%)**: сбрасывает руки → 2 летающих щита-миньона (по 150 HP): таран по линии (20), прикрывают тело от снарядов. Тело топает (круг, 25).
- **Фаза 3 (33–0%)**: ядро-сердце: быстрое, кольца пуль (10), рывок через арену (35). На 15% — ярость, всё на 25% быстрее.
- Каждая фаза видна визуально: теряет части доспеха.
- **Награда:** сильная пассивка 1 из 3; шанс «Кулака Голема»; чертёж + кристаллы; лечение 50% HP.

### 7.8 Проклятия и святилище (п.28, 137–138)
| Сделка | Плюс | Минус |
|---|---|---|
| Сделка крови | Каждое убийство +1 мана | Зелья лечат на половину |
| Сделка жадности | x2 золото | 20% сундуков — мимики |
| Сделка тьмы | +25% крит | Радиус света вокруг героя меньше |
| Сделка спешки | +25% скорость и скорострельность | −25 макс. HP |

Святилище снимает одно проклятие бесплатно, но забирает и его плюс.

### 7.9 Лут, лечение, экономика (п.77, 80–81, 139)
- Враги: золото + сферы маны (притягиваются после зачистки). Сердца и оружие с врагов не падают.
- Сундук после каждой боевой комнаты: золото/зелье ~60%, оружие ~30%, бомба/редкость ~10%. Оружие не чаще 1–2 за этаж.
- Лечение: зелья; 50% HP после босса; комната-фонтан (полное лечение **или** +15 макс. HP); сердце в сундуке +20 HP.
- Золото: обычный враг 1–3, элита 8–12, мини-босс 40, сундук 10–25. Ожидаемо ~150–200 за этаж.

### 7.10 Торговец (п.40)
Оружие + зелья, **без пассивок**. Скидка за репутацию внутри забега. Скупает оружие за 50%. Нападение на торговца = бой с мини-боссом.

## 8. Мир и генерация

### 8.1 Структура этажа (п.41)
- Граф этажа процедурный, с гарантиями (§8.2).
- Боевые комнаты собираются из **чанков 8×8 тайлов** — проверенных префабов на Tilemap: форма, укрытия, лужи, ловушки по правилам биома.
- **Ориентиры**: 1–2 редкие уникальные ручные комнаты на биом (для Замка ◆: разрушенный тронный зал).
- Спец-комнаты (босс, кузница, пазлы, ивенты) — ручные сцены/префабы.
- **Модификаторы комнаты** (10–15% шанс): тьма, низкая гравитация пуль, «пол — лава» на 10 с, двойные элиты.
- Форма: комнаты разных размеров + коридоры, непрямоугольные арены, длинные залы (п.39).

### 8.2 Гарантии генератора (старый GDD §14)
- Есть хотя бы один достижимый путь от старта к выходу.
- Сервис (хил/мана/торговец) не блокирует единственный маршрут.
- Секрет никогда не обязателен для победы.
- Элита — опциональное ответвление с лучшей наградой.
- Нет пропастей с мгновенной смертью.
- Кузница и святилище не в одной комнате с обязательной боевой волной.

### 8.3 Комнаты среза
Бой · сундук · кузница · торговец · мини-босс · секрет (за стеной, ломается бомбой, п.27) · фонтан · клетка помощника · святилище · босс · ориентир.

### 8.4 Окружение (п.36)
Разрушаемые укрытия и бочки, ловушки. Лужи/трава/масло и реакции с ними — 1.0 (п.120).

## 10. Подача: арт, звук, game feel

Полные правила арта — `Research/07_ART_BIBLE_SPEC.md`.

### 10.1 Арт (п.92–93, 97, 143, 147, 150)
- Пиксель-арт. Тайл 32 px, PPU 32, герой 32×32 (24–32 px ростом), боссы 96–160 px. База 640×360, x3 → 1080p.
- Палитра **Endesga 32**, все спрайты строго в ней.
- Пропорции чиби, голова ~1/2 роста.
- Направления: герои **4** в срезе (вверх / вниз / вбок с зеркалом), 8 — к 1.0; обычные враги 2 (зеркало); босс 4.
- Свет: тёмные комнаты + тёплые источники (URP 2D Lights: факелы, снаряды, взрывы).
- Стиль «лом и швы»: швы, заклёпки, ржавчина, угли, пульсирующее Сердце.

### 10.2 Game feel (п.98, 101)
- Цифры урона (крит оранжевый и крупнее, отключаемо).
- Тела, обломки, копоть, гильзы остаются до конца комнаты. Без крови.
- Белая вспышка врага 0.05 с всегда; hit-stop только на кувалде и критах в ближнем бою; тряска слабая и отключаемая.
- Каждое важное событие (попадание, подбор, сплав, смерть врага, выбор награды) — короткий визуально-звуковой отклик (D9, C15).

### 10.3 Звук (п.62, 102–103)
- Музыка: трек биома в 2 слоях (спокойный в коридорах + барабаны при запирании дверей), отдельные треки босса и кузницы, переходы без стыков. AI-генерация с коммерческой лицензией.
- SFX: лицензионные паки + доработка.
- Голоса: текст + «бубнение» у каждого персонажа, без озвучки.
- AI-контент раскрывается по правилам Steam (`Research/03_AI_GAMEDEV_ARTICLES.md`).

### 10.4 Локализация
Срез: RU / EN / PL (п.123). 1.0: RU, EN, UA, PL, DE, ES, ZH-Hans, PT-BR (п.61). Тексты — по ID (E1).

## 12. Не делаем (C8)

**В срезе:**
- сюжет, диалоги, Франкен в кадре;
- кооп, геймпад, сейв между этажами;
- реакции статусов с окружением;
- пассивки сплава и плоские +статы;
- 8 направлений героя.

**Никогда:**
- внутриигровые покупки, донат-витрина;
- реакции между статусами на врагах;
- превью результата сплава и пересплав;
- пропасти с мгновенной смертью;
- нечестные атаки без телеграфа;
- кровь;
- копирование персонажей, UI, названий, музыки и ассетов Soul Knight и других игр (C13, G9).

**Не взято (пока, п.145):**
- «Сердце забирает выброшенное оружие»;
- переименование героев;
- отказ от цели «200+ оружий»;
- своя автонаводка;
- перенос режима защиты.
