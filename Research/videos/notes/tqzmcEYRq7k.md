(Фабрика-игра в Unity, пайплайн 3D-модель - анимация - VFX через GPT-6 Astra + Blender MCP.)

## 1. Архитектура кода
- **Описывай каждую новую постройку отдельным диздоком-файлом и ссылайся на него из основного.** — Агент читает основной док и переходит во вложенную заметку (в Obsidian: «извлечь заголовок» в отдельную заметку). [00:09]
- **Анимации экспортируй отдельными циклами (idle, work, переходы on/off), а не одним клипом.** — Работа может идти долго при загрузке ресурсами, idle тоже; клипы должны быть зациклены и вставляться в Unity-аниматор. [00:15]
- **Логику и интерфейс постройки разделяй по задачам: при создании модели не делай логику/анимации/эффекты.** — Каждый чат/агент отвечает за один тип ассета. [00:10] [00:11]

## 2. Работа с ИИ-агентами
- **Один чат = одна стадия пайплайна (3D, анимации, VFX, фиксы, main-игра).** — Узкий контекст, можно запускать параллельно для разных механик. [00:10] [00:15] [00:23]
- **Дай агенту CLI/MCP для движка и Blender.** — Агент сам запускает Blender, подключается к MCP, моделирует. Автор предпочитает CLI MCP как более эффективный. [00:02]
- **Давай агенту ссылку на статью/гайд и проси «скажи, что добавить в AGENTS.md», решение принимай сам.** — Так обновлял AGENTS.md под новую модель. [00:03]
- **Держи один общий AGENTS.md для всех проектов.** — Автор использует его везде. [00:03]
- **Внеси art direction как обязательное правило в AGENTS.md: нет direction - не делать ассеты, запросить у пользователя.** — Не даёт агенту самому придумывать стиль. [00:11]
- **После каждой удачной стадии проси упаковать процесс в пайплайн-файл (toml/md) с шаблоном запроса и правилами.** — Другой агент реюзает процесс без выдумывания с нуля; пайплайн можно дополнять. Автор сократил длинный пайплайн, чтобы не раздувать. [00:14] [00:16] [00:19]
- **Для 3D требуй одну картинку со всеми проекциями, а не отдельные.** — Быстрее править и правки применяются везде сразу. [00:13] [00:14]
- **Давай нейронке концепт в нескольких проекциях перед 3D, иначе она «додумывает быстро и плохо».** — Нужны слева/справа/спереди/сзади/сверху/снизу + изометрия. [00:11] [00:13]
- **Сначала генерируй 6 вариантов 2D-картинок (image gen) и выбирай лучший.** — Дешёвый способ выбрать стиль/форму до 3D. [00:12]
- **Давай референсы (2-4 картинки с Pinterest/Google) и для 3D, и для VFX.** — Эффект собирается точнее. [00:09] [00:20]
- **Для точных правок описывай, что не так словами («слишком топорно, по прямой, нужно плавно одним движением»).** — Так исправлен полёт молота. [00:15]
- **Выставляй reasoning effort высоким для сложных задач.** — Для печи автор поставил Astra на high (до этого medium). [00:22]
- **Следи за лимитом подписки.** — Весь проект (наковальня + печь + интеграция) ушёл ~21% недельного лимита ($100-подписка), т.е. ~10-15 таких «файликов». Печь целиком ~2 часа. [00:23] [00:24]

## 3. Геймдизайн и GDD
- **Для новой механики пиши диздок: логика, референсы, краткое описание деталей, список анимаций, VFX.** — Диздок описывает функцию (что модель доносит игроку), не визуал. [00:07] [00:10]
- **Не делай интерфейс для механики на старте.** — Сначала превращение слиток -> пластина. [00:10]
- **Осталось делать самому: баланс, контент, гейм-дизайн.** — Руками умеешь меньше, думать надо больше. [00:25]

## 4. Арт и ассеты
- **Начни с Art Direction: стиль, сеттинг, референсы, вайб/атмосфера (словами).** — Все ассеты должны сочетаться; direction может отличаться для 3D, UI, анимаций, VFX. [00:03] [00:05]
- **Формулируй стиль через игру-пример («как в Cuphead»).** — Так стиль чётко задаётся. [00:04]
- **Проверяй сочетание стиля и сеттинга (классическое фэнтези в картун — странно).** — Найди рабочий пример в играх/фильмах, иначе тестируй. [00:04]
- **Храни Art Direction в Obsidian как док с картинками-референсами, давай агенту путь к файлу.** — «Скопировать путь от корня» и вставить в чат. [00:06]
- **Пайплайн: диздок -> варианты 2D -> проекции -> 3D в Blender -> анимации -> VFX -> Unity.** — Повторяет реальный геймдев (концепт-художник, 3D, аниматор, VFX). [00:07] [00:17]

- **Проверяй модель/эффект в реальной камере игры, не только в Blender.** — На белом фоне эффект не виден; в игре масштаб/камера менялись (камеру пришлось приблизить). [00:20] [00:22]
