# Forge of the Fallen — Art Bible (спецификация масштаба и стиля)

Версия 1.0 · 26.11.2026. Обязательна для любого арта: рисует человек, Claude или генератор.
Основа: п.92–97, 100–101, 143, 147, 150; правила D1–D4, D7–D10, G8, G9 (`RULES_DIGEST.md`). Референсы: `ART_REFS.md`. Пайплайн: `06_ASSET_PIPELINE_MCP.md`.

## 1. Стиль «лом и швы» (п.143)
Всё в мире Франкена **сшито и склёпано**: швы-скобы, заклёпки, сварные полосы, ржавые пластины, тлеющие угли в щелях, пульсирующее тёплое Сердце.
- Читаемость на скриншоте: «узнаю по одному кадру», не похоже на Soul Knight.
- Тон: тёплая тёмная сказка, лёгкий юмор, без крови. Урон показываем искрами, трещинами, дымом, копотью.
- Чиби-пропорции: голова ~1/2 роста (п.93).
- Мотив шва есть на всём, что связано со сплавом и Сердцем: гибриды, химеры, кузница, Франкен, UI редкости «Франкен».

## 1.1 Утверждённое направление (п.174)
- **Геймплей:** `concepts/v2/g3.jpg` «Замок-завод» — замок, наполовину поглощённый машинерией Франкена: трубы, цепи, конвейеры, пар, печные решётки, ржавые строительные леса. Холодный сине-зелёный металл (`#3a4466` `#5a6988` `#193c3e`) против горячего света печей (`#f77622` `#feae34`). HUD — манометры и латунные трубки.
- **Главное меню:** `concepts/v2/m1.jpg` «Разлом» — вид в пропасть, падающие дома и мосты, Сердце светится внизу; логотип из клёпаного ржавого металла с шестернёй. Годится и как основа капсулы Steam.
- Концепты — ориентир настроения и композиции, не спрайты: масштаб и палитру берём строго из §2–§3.

## 2. Масштаб (единый, без исключений)
| Параметр | Значение |
|---|---|
| Базовое разрешение | 640×360, целочисленный x3 → 1920×1080 (Pixel Perfect Camera) |
| PPU | 32 у всех спрайтов |
| Тайл | 32×32 |
| Чанк комнаты | 8×8 тайлов (256×256 px) |
| Герой | канвас 64×64, рост 40–48 px (решение 27.11.2026: больше деталей; запас канваса — под оружие и анимации) |
| Обычный враг | канвас 32×32 (крыса/мышь 16–24 px в канвасе 32×32) |
| Крупный враг / элита / химера | канвас 48×48 |
| Мини-босс | канвас 64×64 |
| Босс | канвас 96–160 px (Голем: 128×128) |
| Оружие в руке | по классу размера (§5.1): малое ≤16 px (канвас 16×16), среднее 24–36 px (32×16 / 32×24 / 32×32), большое 40–48 px (48×16 / 48×24 / 48×48); лежит вправо или по диагонали (угол в `spriteForwardAngle`), точка хвата отмечена |
| Иконка оружия в UI | 32×32, тот же спрайт без поворота |
| Снаряд | 8×8 или 16×16 |
| Подбираемые предметы | 16×16 |
| UI-элементы | кратно 1 px исходной сетки 640×360; шрифт — пиксельный, кириллица + польские символы |

Правило: «пиксель одного размера». Запрещено масштабировать спрайт в сцене (scale ≠ 1) и смешивать разные PPU.

## 4. Линия, свет, тени
- Контур: 1 px, тёмный цвет из семейства объекта (не чистый чёрный); внешний контур у персонажей и предметов, у тайлов — без контура.
- Свет сверху-слева; 1 тон тени + 1 тон блика на материал, без градиентов и сглаживания.
- Без anti-aliasing и полупрозрачных пикселей в спрайтах (альфа 0 или 255).
- Тень персонажа — простой овал (отдельный спрайт).
- Динамический свет — URP 2D Lights (факелы, снаряды, взрывы, Сердце). Персонажи, враги, пропсы и стены получают карту нормалей как вторичную текстуру спрайта `_NormalMap` (тот же размер канваса, свет сверху-слева не запекать в альбедо сильнее 1 тона); тени — ShadowCaster2D. Решение 26.11.2026, пример: `Assets/_Project/Sandbox/LightingTest/`. Bloom только на огне, магии, порталах, редкости (старый GDD §17).

## 5. Анимация
| Объект | Направления | Анимации (кадры) |
|---|---|---|
| Герой (срез) | 4: вверх, вниз, вбок (+зеркало) (п.147) | idle 4, run 6, dash 3, hit 2, death 6, skill 4–6 |
| Обычный враг | 2: вбок + зеркало (п.100) | idle 4, move 4–6, telegraph 2–4, attack 3–4, hit 2, death 4–6 |
| Босс | 4 | по фазам; потеря частей видна (п.88) |
| Оружие | вращается за прицелом 360° (п.147), без покадровых направлений | атака — по типу хвата (§5.1), кадры только у лука и VFX |
- Частота: 10–12 fps для движения, 12–15 fps для эффектов.
- Телеграф атаки врага: замах 0.4–0.8 с + свечение оружия + красная зона на полу для больших атак (п.86).
- ИИ-покадровую анимацию **не** принимать как финал без чистки: форма «прыгает» между кадрами (D10).

## 5.1 Оружие в руках: слой, хват, размер, атака (решение владельца 27.11.2026)
Герой — цельная покадровая анимация **без оружия** (Рыцарь — состояние PixelLab `NoSword`, Маг — состояние без посоха). Оружие — отдельный слой у руки, крутится за прицелом. Смена оружия меняет только слой, тело не перерисовываем.

**Единый стиль.** Оружие генерируется тем же инструментом и в том же масштабе, что герой: стиль-референс — спрайт Рыцаря, палитра Endesga 32, контур 1 px тёмным цветом семейства, свет сверху-слева. Спрайт оружия в сцене не масштабируется (scale = 1). Оружие не должно выглядеть «чужим предметом».

**Размер** (герой 48 px ростом):
| Класс | Длина | Оружие |
|---|---|---|
| S малое | 12–16 px (≤ 1/3 роста) | гвоздомёт |
| M среднее | 24–36 px (≤ 3/4 роста) | меч, сабля, обрез, лук, арбалет, все посохи |
| L большое | 40–48 px (≤ рост) | кувалда, Тарахтелка, Кулак Голема |
Больше роста героя — только отдельно утверждённое «огромное» оружие.

**Тип хвата** (поле данных `holdType`) и точки в пикселях спрайта: `gripPixel` (основная рука), `secondGripPixel` (вторая рука, у двуручных), `muzzlePixel` (дуло / навершие / тетива).
| Хват | Оружие | Как держит |
|---|---|---|
| OneHandMelee | меч, сабля | в ведущей руке, клинок по прицелу; у Рыцаря щит остаётся на другой руке |
| TwoHandHeavy | кувалда, Кулак Голема | обе руки, вне атаки — на плече |
| Pistol | гвоздомёт | одна рука вытянута к прицелу |
| TwoHandGun | обрез, Тарахтелка, арбалет | приклад у тела, вторая рука на стволе |
| Staff | все посохи | одна рука, навершие вверх-вперёд |
| Bow | лук | одна рука на рукояти, вторая у тетивы |
Руки: спрайт перчатки 4×4 px у каждого героя (свои цвета), рисуется поверх рукояти в `gripPixel` и `secondGripPixel` — хват читается. Точка руки у тела задана по направлению (юг/бок/север) и качается на 1 px с кадрами бега.

**Атака — по типу хвата, а не по оружию** (подходит всем 13 видам и гибридам):
| Хват | Анимация слоя | Спрайты |
|---|---|---|
| OneHandMelee | взмах дугой −100° → +60° за 0.12 с, возврат 0.1 с | росчерк 3 кадра (VFX) |
| TwoHandHeavy | замах вверх 0.25 с → удар → hit-stop → возврат | пыль/трещина 3 кадра |
| Pistol, TwoHandGun | откат назад 2 px (TwoHandGun 3 px) + подброс 4°, возврат 0.08 с | вспышка дула 2–3 кадра; Тарахтелка — раскалённый ствол (тинт) |
| Staff | подъём навершия 6°, свечение | навершие 3–4 кадра |
| Bow | натяжение по удержанию | лук 3 кадра: покой, половина, полное |
Проверка: `Tools/art/check_weapon.py` (класс размера, канвас кратен 8, палитра, альфа 0/255).

## 6. Гибриды и химеры из слоёв (п.95, 142)
- Гибрид оружия = спрайт более редкого родителя + сменная деталь второго (дуло / клинок / кристалл / приклад) + тинт элемента + слой швов/скоб. Слоты деталей у каждого оружия размечены (anchor-точки) в данных.
- Химера = тело основного врага + деталь второго + скобы/швы Сердца + свечение `#f77622`.
- Отдельный спрайт под каждую пару **не рисуем**.

## 7. Импорт в Unity
- Texture Type Sprite (2D and UI), Filter Mode **Point**, Compression **None**, Generate Mip Maps **off**, PPU **32**.
- Pivot: персонажи — низ по центру (ноги), оружие — точка хвата, снаряды — центр.
- Спрайт-листы: Aseprite → `.aseprite` через пакет 2D Aseprite Importer или PNG-лист + JSON; имена кадров `{object}_{anim}_{dir}_{nn}`.
- Нейминг файлов: `hero_knight_run_side.png`, `enemy_skeleton_sword_attack.png`, `weapon_nailgun.png`, `tile_castle_floor_01.png`.

## 8. Проверка (автоматическая, до коммита ассета)
Скрипт (сделать в пайплайне, `06_ASSET_PIPELINE_MCP.md`):
1. размер канваса совпадает с таблицей §2;
2. все непрозрачные пиксели — из Endesga 32;
3. альфа только 0/255;
4. нет масштабированных «больших пикселей» (проверка, что изображение не является апскейлом).
Плюс ручная проверка в настоящей камере, комнате и свете игры (D7).

## 9. Порядок производства арта (D1, G8)
1. Сначала **серая коробка** и плейтест (п.151) — на плейсхолдерах: цветные формы в палитре, правильные размеры канвасов.
2. Параллельно, без влияния на код: **целевой скриншот** (1 кадр 640×360: Рыцарь, 3 скелета, кузница, комната Замка) в 3–6 вариантах → выбор владельца (D1, D3). Это ориентир, не финальный арт.
3. После подтверждения, что играть интересно: финальный арт по этой спецификации; объём заранее посчитан (§10, D4).
