## 3. Что сделать владельцу
1. Прочитать `Docs/GDD.md` и ответить на §13 (10 вопросов) и спорные места из `04` (§4 ниже).
2. На машине, где будет код: Unity Hub + Unity 6 LTS, открыть проект, проверить `unity status` (Unity CLI).
3. `brew install git-lfs` (или на Windows: `git lfs install`).
4. Отозвать GitHub-токен, лежащий открытым текстом в `~/.gemini/settings.json`.
5. Позже, после серой коробки: Retro Diffusion ($5) + MCP-ключ; Aseprite.

## 5. Первая задача для кодинга: серая коробка (п.151)
Делается в отдельной сессии на машине с Unity. Спецификация (B5):
- **Сцена** `Greybox` собрана в редакторе: комната 2×2 чанка (16×16 тайлов) с Tilemap-стенами, 2 двери, точки спавна волн, кузница-префаб.
- **Герой** Рыцарь (цветной прямоугольник 32×32 в палитре): движение WASD, прицел мышью, dash (1 заряд, кулдаун 1 с, i-frames), HP 120 / броня 60 / мана 150 из `HeroDefinition`.
- **Оружие** 2 штуки из данных: Вечный меч (18, 0 маны, взмах) и Гвоздомёт (8, 1 мана, оглушение 0.5 с). 2 слота, смена Q, подбор третьего роняет текущее.
- **Сплав**: E кладёт оружие на плиту, рычаг → `FusionService` → гибрид падает на пол; доминанта A/B/середина, джекпот 2–3%.
- **Враг** скелет-мечник из `EnemyDefinition` (40 HP, 12 урона, замах 0.5 с с телеграфом).
- **Комната**: вход → двери закрываются → 2 волны (3 + 4 скелета) → сундук → двери открываются.
- **Готово, если**: компиляция без ошибок, Console чистая, EditMode-тесты на урон/броню/сплав зелёные, ни одного `new GameObject` для видимых объектов, все числа в ScriptableObject, владелец сыграл и принял.
